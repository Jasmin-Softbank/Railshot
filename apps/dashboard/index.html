앱 배포하기

기존 앱 업데이트

앱과 배포 환경은 유지됩니다. 파일·폴더·저장소 이름을 바꿔도 앱 이름은 바뀌지 않습니다.

01

소스 선택

앱 파일 또는 폴더를 선택하세요 ZIP 파일을 여기에 끌어 놓을 수도 있습니다.
또는

같은 환경에 같은 이름의 내 앱이 있으면 업데이트합니다. 별도 앱으로 배포하려면 다른 이름을 입력하세요. 영문 소문자로 시작하는 3~30자이며 숫자와 하이픈을 사용할 수 있습니다.

02

배포 환경

배포 환경 선택

등록된 인프라 연결 상태를 확인한 뒤 배포합니다.

OpenStack 인프라 등록

등록 요청을 만들고 10분 동안 유효한 일회성 토큰을 발급합니다. OpenStack 프로젝트·인증 정보는 고객 노드에서 직접 설정합니다.

고객 노드에서 실행하면 install.sh 파일을 내려받습니다. 설치 실행에는 아래 필수 파일 묶음과 설정 JSON이 별도로 필요합니다.

고객 노드에서 아래 토큰 접수 파일을 실행하고 이 토큰을 입력하세요.

토큰 접수 파일 다운로드

단독 파일 실행: python3 claim_token.py --service-url https://서비스-주소. ZIP에서는 deployment/bootstrap/claim_token.py 경로를 사용하세요.

install.sh 파일 다운로드 필수 파일 묶음 다운로드

실행에는 필수 파일 묶음과 고객 노드에서 작성한 설치 설정 JSON이 필요합니다. 아래 install.sh 코드만 복사한 경우에도 동반 파일을 준비하세요.
