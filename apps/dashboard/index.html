기존 앱 업데이트

앱과 배포 환경은 유지됩니다. 파일·폴더·저장소 이름을 바꿔도 앱 이름은 바뀌지 않습니다.

01

소스 선택

앱 파일 또는 폴더를 선택하세요 ZIP 파일을 여기에 끌어 놓을 수도 있습니다.
또는

같은 환경에 같은 이름의 내 앱이 있으면 업데이트합니다. 별도 앱으로 배포하려면 다른 이름을 입력하세요. 영문 소문자로 시작하는 3~30자이며 숫자와 하이픈을 사용할 수 있습니다.

02

배포 환경

배포 환경 선택

등록된 인프라 연결 상태를 확인한 뒤 배포합니다.

OpenStack 인프라 등록

프로젝트·사용자 ID와 연계 키를 백엔드에 등록합니다. Keystone 인증정보는 고객 노드에서 install.sh 실행 시 직접 입력하세요.

현재 install.sh는 이 토큰을 사용한 WireGuard 연결을 아직 지원하지 않습니다.

install.sh 파일 다운로드 필수 파일 묶음 다운로드

실행에는 필수 파일 묶음과 고객 노드에서 작성한 설치 설정 JSON이 필요합니다. 아래 install.sh 코드만 복사한 경우에도 동반 파일을 준비하세요.
