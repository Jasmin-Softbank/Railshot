# 복제 정책 결정

사용자 결정: 운영 정책은 선택 입력이며 동기 복제를 기본 적용하고 비동기 선택도 제공합니다.

구현의 잠정 안전 기본값: synchronous_mode_strict=true, synchronous_node_count=1. 동기 복제본이 없으면 쓰기를 차단합니다. 이는 사용자께서 쓰기 중단 정책을 별도로 확정하셨다는 뜻이 아니므로 운영 적용 전 요구사항 확인과 장애 시험이 필요합니다.

백업은 목적지 미정 상태에서 임의로 활성화하지 않습니다. backup_enabled=false는 보호 완성을 뜻하지 않습니다. 보관 기본값 retention_full=7은 전체 백업 개수이며 운영 요구에 맞게 변경해야 합니다.

원격 독립 standby 클러스터, 자동 거점 승격, 운영 중 업그레이드는 별도 기능으로 남깁니다.
