## 인증과 원격 실행

2:40:50에서 논의한 인증 수단은 **Keystone unscoped token**입니다. 이 토큰에는 project 범위·role·service catalog가 없지만, 허용된 project의 scoped token을 발급받는 데 사용할 수 있습니다. 인증 비밀로 취급해야 합니다. [Keystone 공식 설명](https://docs.openstack.org/keystone/latest/admin/tokens-overview.html).

현재 `CP_API_TOKEN`은 Controller 호출자를 인증하고, application credential은 OpenStack project 권한을 위임합니다. 회의에서 제안한 unscoped token 교환·갱신·폐기·project 선택은 현재 Controller의 외부 API에 구현되어 있지 않습니다. 플랫폼 로그인 OIDC와 GitHub→AWS OIDC는 이 경로와 별도의 인증 관계입니다. [Application credentials](https://docs.openstack.org/keystone/latest/user/application_credentials.html).

현재 Ansible 실행기는 SSH, known_hosts, sudo를 사용합니다. 공인 TCP 22를 열지 않고 VPN 내부에서 SSH로 접속할 수 있습니다. SSH 자체를 사용하지 않으려면 AWS SSM 또는 고객 호스트의 local runner 등 다른 실행 수단을 연결해야 합니다. WireGuard는 사설망 통신을 제공하며 명령 실행을 대신하지 않습니다. [Ansible 연결 방식](https://docs.ansible.com/projects/ansible/latest/inventory_guide/connection_details.html).
