# 검증 계획

1. 정적 검사: 전체 YAML, Ansible 문법, 작성 규칙, 사용자 정책 덮어쓰기 계약.
2. 입력 검사: 이름 누락·정책 오타·중복 주소·etcd 부족·비밀정보 누락 시 변경 전 실패.
3. 신규 Ubuntu 24.04 시험 서버에서 전체 실행, 주 서버 하나·복제본 합류·동기 설정 확인.
4. 동일 입력 재실행 시 데이터·인증정보 보존과 불필요한 변경 확인.
5. 동기 복제본 중단 시 기본 엄격 모드의 쓰기 차단 및 복구 후 재개 확인.
6. 주 서버 중단·통신 단절·etcd 과반수 상실 시 이중 주 서버 여부와 실제 복구 시간 측정.
7. 중계 경로로 새 연결이 새 주 서버에 도달하는지 확인. 기존 연결의 자동 복구를 가정하지 않음.
8. 별도 마운트 저장소에 백업 후 고립된 빈 대상에 복원, 알려진 시험 데이터 비교.
9. 관측 기반과 연결 후 실제 경보 발생·복구 확인.

모든 장애·복원 시험은 전용 시험 환경에서만 수행합니다. 실제 운영 대상의 파괴적 시험은 이번 자동 실행 범위가 아닙니다.
