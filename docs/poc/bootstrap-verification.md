2026-10-02 검증 담당 세션에서 최종 실행했습니다. 검증 환경은 macOS / Python 3.11.15이며, 지원 대상 Ubuntu 24.04의 실행 검증을 대신하지 않습니다.

- `PYTHON=/tmp/jasmin-bootstrap-verify/bin/python bash ci/scripts/check-bootstrap.sh`: 40개 테스트와 6개 하위 사례 통과. 셸 문법 검사 포함.
- Python `compileall`: 설치 프로그램과 OpenStack 모듈 구문 검사 통과.
- 실제 배포 소스를 임시 설치 경로로 복사한 후 원본 저장소 밖에서 명령 도움말 실행 및 동일 배포본 재설치: 통과.
- `git diff --check`: 기존 추적 파일 변경의 공백 오류 없음.
- 외부 서버 등록, 고객 네트워크 변경, OpenStack 자원 생성은 실행하지 않았습니다.

`PYTHON=/path/to/python ci/scripts/check-bootstrap.sh`를 실행합니다. 해당 Python 환경에 requirements.lock 및 pytest가 필요합니다. 기존 PostgreSQL/Ansible 테스트와 별도 검증합니다.

검증 범위: 등록 응답 거부, 터널 설정의 경로 제한, OpenStack 모의 응답과 권한 판별, 파일 권한·심볼릭 링크 거부, 암호화 왕복과 변조 거부, 상태의 비밀정보 제거, 인증·접근 설정의 중복/실패 처리. 실제 포함 사례와 실행 개수는 테스트 실행 결과를 기준으로 하십시오.

## 실환경 검증: 미수행

실제 서비스 등록 서버, 고객 OpenStack 인증정보, Ubuntu 고객 노드가 제공되지 않았으므로 다음 항목은 미검증입니다.

1. Ubuntu 24.04 깨끗한 노드의 의존성 설치와 재부팅 후 실행.
2. 실제 등록 키 소비, 응답 유실 후 동일 요청 복구, 고객별 격리.
3. WireGuard 연결, UDP 차단, 연결 중단·복구와 기존 라우팅 보존.
4. 관리자 인증, 전용 계정/역할/자격증명 생성, 만료·폐기 후 거부.
5. 실제 서비스와 할당량 진단 결과 대조.
6. 시험 가상 머신 생성 후 SSH 접근, 허용하지 않은 출발지 접속 거부.
7. 부분 실패 후 재실행, 기존 고객 자원 보존, 등록 폐기와 로컬 제거.

자동 테스트 통과는 위 항목의 성공이나 운영 준비 완료를 뜻하지 않습니다.

## 검증 책임자 독립 확인

2026-10-02, macOS의 Python 3.11.15에서 실제 설치 소스를 임시 디렉터리에 복사한 뒤 원본 저장소 밖의 작업 경로에서 복사된 `client_setup.main --help` 실행과 동일 설치 묶음 재설치를 확인했습니다. 이 검증은 네트워크나 시스템 설정을 변경하지 않았습니다. 대상 Ubuntu 24.04의 실제 실행 검증을 대신하지 않습니다.

## 작업 요청 에이전트 독립 검증
